# Laporan Proyek Machine Learning: Prediksi Kualitas Latihan Angkat Beban

## Deskripsi
Analisis ini memprediksi cara melakukan angkat beban (variabel `classe`) menggunakan data accelerometer.

## File
- `analysis.Rmd` : Kode analisis lengkap
- `analysis.html` : Laporan kompilasi
- `predictions.csv` : Hasil prediksi
## Cara Reproduksi
1. Jalankan `analysis.Rmd` di RStudio
2. Pastikan paket berikut terinstall:
   - `caret`
   - `randomForest`
